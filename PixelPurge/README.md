# PixelPurge

아이폰 사진 라이브러리를 기기 안에서 분석해서 **중복·유사 사진**, **스크린샷**, **용량이 큰 동영상**을 찾아 정리하도록 도와주는 앱이에요. 어떤 사진도 외부로 전송되지 않고, 모든 분석은 폰(또는 빌드하는 Mac) 안에서만 이루어져요.

이 문서는 개발 경험이 없어도 따라할 수 있도록 Mac에서 빌드해서 본인 아이폰에 설치하는 과정을 처음부터 끝까지 설명해요.

## 준비물

- **Mac** (macOS Ventura 13 이상 권장)
- **아이폰** + 충전 케이블 (Wi-Fi로도 가능하지만 처음엔 케이블 연결 추천)
- 아이폰에서 쓰는 **Apple ID** (아이클라우드 로그인용 ID면 충분, 별도 유료 개발자 계정 필요 없음)

## 1단계 — Xcode 설치 (Mac)

1. Mac에서 **App Store** 앱을 열고 "Xcode" 검색 후 설치 (용량이 크고 시간이 꽤 걸려요, 와이파이 연결 상태에서 진행)
2. 설치 후 Xcode를 한 번 실행해서 추가 구성 요소 설치가 끝날 때까지 기다리기

## 2단계 — 프로젝트 압축 풀기

1. 전달받은 `PixelPurge.zip` 파일을 더블클릭해서 압축 해제 (원하는 폴더, 예: 바탕화면)

## 3단계 — 프로젝트 파일 생성하기 (터미널)

이 프로젝트는 Xcode 프로젝트 파일(.xcodeproj)을 저장소에 직접 넣는 대신, [XcodeGen](https://github.com/yonaskolb/XcodeGen)이라는 무료 도구로 그 자리에서 생성하는 방식이에요. 아래 명령어를 **터미널(Terminal) 앱**에 그대로 복사해서 붙여넣고 Enter 하면 돼요. (Spotlight에서 "터미널" 검색하면 실행됨)

```bash
# Homebrew가 없다면 먼저 설치 (이미 있다면 건너뛰어도 됨)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# XcodeGen 설치
brew install xcodegen

# 압축 푼 폴더로 이동 (경로는 본인 상황에 맞게 수정)
cd ~/Desktop/PixelPurge

# Xcode 프로젝트 생성
xcodegen generate

# Xcode에서 열기
open PixelPurge.xcodeproj
```

## 4단계 — 내 Apple ID로 서명하기

1. Xcode가 열리면 왼쪽에서 최상단 **PixelPurge** 프로젝트 클릭 → 가운데에서 **Signing & Capabilities** 탭 클릭
2. **Team** 드롭다운에서 본인 Apple ID 선택
   - 목록에 없다면 Xcode 메뉴 → Settings(환경설정) → Accounts → `+` 버튼으로 Apple ID 로그인 후 다시 선택
3. "Automatically manage signing" 체크되어 있는지 확인

## 5단계 — 아이폰에 설치하기

1. 아이폰을 케이블로 Mac에 연결 → 아이폰에서 "이 컴퓨터를 신뢰하시겠습니까?" 뜨면 **신뢰** 선택
2. Xcode 상단 중앙의 실행 기기 선택 메뉴에서 **본인 아이폰** 선택 (시뮬레이터 말고 실제 기기)
3. 좌측 상단 ▶ **실행 버튼** 클릭 → 빌드 후 자동으로 아이폰에 앱이 설치되고 실행됨

### 처음 실행 시 아이폰에서 한 번 더 할 일

앱이 안 열리고 "신뢰할 수 없는 개발자" 경고가 뜨면:

1. 아이폰 **설정 → 일반 → VPN 및 기기 관리(VPN & Device Management)**
2. 본인 Apple ID로 된 개발자 프로필 선택 → **신뢰**

이후 홈 화면에서 PixelPurge 앱을 다시 실행하면 정상적으로 열려요.

> **참고**: 유료 개발자 계정(연 $99) 없이 무료 Apple ID로 설치하면, 설치된 앱이 **7일 후 만료**돼요. 만료되면 데이터 손실 없이, 위 5단계(Mac에 연결 후 ▶ 실행)만 다시 반복하면 재설치돼요.

## 앱 사용법

1. 첫 실행 시 "사진 접근 허용하기" → 사진 접근 권한 허용
2. **홈** 탭: 전체 저장 용량 요약, 스크린샷/동영상 바로가기, "중복 사진 찾기" 버튼
3. "중복 사진 찾기" 누르면 사진을 분석해서 비슷한 사진끼리 그룹으로 묶어 보여줘요
4. 그룹을 눌러서 남길 사진(추천 보관 표시)과 지울 사진을 확인 후 삭제
5. **스크린샷**, **동영상** 화면에서도 여러 장 선택 후 한 번에 삭제 가능

### iCloud 용량을 실제로 줄이려면

아이폰에서 사진을 지우면 바로 없어지는 게 아니라 **"최근 삭제됨" 앨범에 30일간 보관**돼요 (그동안은 iCloud 용량도 계속 차지함). 용량을 바로 확보하려면:

- 사진 앱 → 앨범 → 최근 삭제됨 → **모두 비우기**

## 알아두면 좋은 점 (한계)

- **중복 판정 방식**: 이미지를 8×8 흑백 축소본으로 만들어 밝기 패턴을 비교하는 "지각 해시(perceptual hash)" 방식이에요. 완전히 똑같은 사진은 물론, 살짝 편집되거나 재압축된 비슷한 사진도 잡아내지만, 100% 정확하진 않아요 — 가끔 진짜 다른 사진이 묶이거나, 미묘하게 다른 사진이 안 묶일 수 있어요. 삭제 전에 꼭 한 번 훑어보고 확인하는 걸 추천해요.
- **용량 표시는 추정치**: iCloud에만 있고 기기에 다운로드되지 않은 사진은 용량 계산에서 제외돼요 (불필요한 다운로드를 막기 위해서예요).
- **동영상은 중복 검사 대상 아님**: 현재는 사진(정지 이미지)만 중복 검사하고, 동영상은 "용량 큰 순" 목록만 제공해요.
- 삭제는 iOS 시스템이 항상 한 번 더 확인 팝업을 띄워요 (앱이 임의로 우회할 수 없는 Apple의 안전장치예요).

## 프로젝트 구조

```
PixelPurge/
  project.yml                 # XcodeGen 설정 (여기서 .xcodeproj 생성)
  Sources/PixelPurge/
    App/                      # 앱 진입점, 전역 상태(AppState)
    Models/                   # PhotoAssetInfo, DuplicateGroup, LibrarySummary
    Services/                 # 사진 라이브러리 접근, 해시 계산, 중복 그룹핑, 용량 분석
    Views/                    # 화면 및 재사용 컴포넌트
    Utilities/                # 바이트 단위 포맷터
  Resources/
    Assets.xcassets           # 앱 아이콘/색상 (아이콘 이미지는 비어있어 직접 추가 가능)
```
